# KDHOME — Facebook 广告落地页 v3（英文 · WhatsApp 转化）

文件：`index.html`（单文件、无构建依赖、手机端约 6 屏）+ `img/`（9 张本地图片）

- 转化目标：引导用户点击 WhatsApp 按钮添加号码（页面上不显示号码）
- 跳转方式：**K2 方法** —— 所有 CTA 按钮点击后调用 MeetU SDK 的全局函数 `k2()`（自动触发 FB/TikTok 像素转化，再跳 MeetU 后台配置的地址，当前为 qq.com）。页面 HTML 中不写死任何跳转链接
- **图片全部本地化**在 `img/` 目录，不依赖官网，加载更快、不怕官网改版
- 设计：系统常规字体（无外部字体 CDN，国内加载快）、奶油底 + 金色渐变点缀，每个 section 版式各不相同
- 手机端：底部固定悬浮 WhatsApp 按钮（呼吸脉冲特效，调用与正文相同的 wa.me 链接）

## 三、跳转与像素（K2 / MeetU SDK）

- 页面 `<head>` 已引入 `https://api.wenk918d.site/js/meetu-sdk.js`（K2 本体）。
- 所有 CTA 按钮（页头/首屏/4 款产品/优惠块/结尾/手机悬浮条/桌面悬浮钮）点击后统一调用 `k2()`：
  1. 自动触发后台勾选的 FB / TikTok 像素转化事件；
  2. 跳转到 **MeetU 后台按站点配置的地址**（当前该站点配置为 qq.com）。
- **换跳转地址**：在 MeetU 后台改该站点的 URL 即可，页面无需改动。
- **像素 ID**：也由 MeetU 后台按站点下发，页面无需再贴 Pixel 代码。
- 按钮上的 `data-wa-text` 预填话术保留备用（如日后改回直跳 WhatsApp 可用）。

## 五、如何部署

1. 上传**整个目录**（`index.html` + `img/` 文件夹）到静态主机（宝塔/虚拟主机放根目录；Cloudflare Pages / Vercel / Netlify 拖入；或放官网子目录 `usmkdhome.com/fb/`）。
2. Facebook Ads 目标网址填该页面线上地址。
3. 建议：FB 对带 WhatsApp 询盘的落地页较敏感，最好用养过的独立域名/子域名投放。

## 六、安装 Facebook Pixel

`<head>` 顶部有注释 `Facebook Pixel: paste base code right below this comment.`，把 Pixel 基础代码贴在注释下。追踪 WhatsApp 点击转化可给按钮加 `onclick="fbq('track','Contact')"`。

## 七、重要注意事项

1. **用户评价是示例**：3 条评价（Sarah/Daniel/Priya）及头像照片均为占位示例。**投放前必须替换为真实客户评价与头像**（需获客户同意），避免违反 FB 广告政策与虚假宣传风险。
2. **增值包划线价是示例值**：$192 免费包为营销占位设计，请按真实可兑现的赠品调整后再投放。
3. **卖点均有出处**：SUS304 食品级不锈钢、8K 镜面、21 种配色、币锁、按订单生产、全球平板包装（运费按目的地单独报价）——均来自官网原文，请勿添加未经证实的承诺（如"终身质保"）。
4. **价格**：官网价格随配置变动（约 $242–$806），页面采用询价制而非标价，避免价格不符引发审核风险或客诉。
5. 字体使用系统字体栈（无外部字体 CDN），全球任何网络环境都稳定显示。
6. 本地预览：直接双击 `index.html`（图片本地已就绪，字体需联网）。
7. `<meta name="robots" content="noindex">` 已设置（广告落地页通常不参与 SEO），需要收录可删该行。
